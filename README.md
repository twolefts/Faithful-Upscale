# Faithful-Upscale

## Overview

This mod focuses on delivering sharper, more detailed visuals across characters, armor, weapons, and the world — all while preserving the original look and feel of the game.

This mod is very stable and there are no known issues that would result in any crashes.

If you do experience a crash related to memory, use the performance versions of Patch P & O.


## Installation

Extract all "Patch" files into your game's Data folder.

VanillaHelpers mod should be installed.

It is highly recommended that you enable DXVK for using this mod or you will very likely experience memory crashes even without any other addons/mods.

Using Reshade may interfere with DXVK if not installed correctly.


## Contents

- Patch-B–H: World Textures
- Patch-O: Character & Gear Textures (REQUIRES PATCH-P)
- Patch-P: Character & Gear Textures (REQUIRES PATCH-O)
- Patch-Q: Character & Gear Textures (added in 1.18.1 content)
- Patch-I: UI Elements (WIP: May conflict with some addons / do not use unless you use the default UI)
- Patch-L: Loading Screens
- Patch-M: Map Textures (WIP: Minor imperfections expected)

Each patch is optional however Patch-O & Patch-P must be either used together or both disabled.

If you use other patches, just rename them to another letter (after these).


## Performance

Patch-O/P is the most memory-intensive, particularly in areas with many characters (e.g. large cities). 

Disabling it may significantly improve frame rate, performance and reduce RAM usage. 

If you experience issues, disable Patch-O/P or use the performance Patches found within "Performance" folder.

The Performance patch is x2 the original resolution and the Main version is x4.


## Notes

The last update for this mod does not include the new maps added in patch 1.18.1 and later (e.g., Moonwhisper Coast). 

If you need completely accurate world maps, do not use Patch-M.
